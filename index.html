Action

Situation · Task
探究台積電股價飆漲是否對台灣食衣住行產生可量化影響，但各政府資料平台格式不一、時間粒度不同（日級股價 vs 月級民生指標），無法直接關聯。
Action
建立完整 ETL Pipeline，整合 10+ 開放資料平台，以 Python（Selenium、Pandas）清洗原始資料，透過 T-SQL 時序正規化解決粒度對齊問題，將 122,200+ 筆資料匯入 Azure SQL Database，設計含 17 張表的 Star Schema，並以自訂 DAX 公式計算 Pearson 相關係數及領先/落後指標。
Result
在 Power BI 呈現台積電股價與餐飲業、超商營業額的時序關聯視覺化報表，透過大事記工具提示（COVID-19、ChatGPT 等關鍵事件）提供脈絡化洞察；4 人協作 187 commits，展現團隊版本管理紀律。
Key Technical Achievement
自製 Python GUI 工具（tkinter）批次將 Excel 轉為 UTF-8 CSV 並直接上傳 SQL Server，解決重複性資料匯入痛點；自訂 DimDate 時間維度表，支援季 / 月 / 日多層級分析。
